UNIFIED MAP: DIPoles → BYTES → GROUPS → CONTINUUM
=================================================================

Physical / combinatorial layer
  Six oriented dipole pairs per 12-bit chirality frame (A12, B12)
  24-bit carrier = active face + record face
  Reachable set Omega: 4096 states = 2^12 = |H|^2 (horizons |H| = 64)

Instruction layer
  8-bit byte = 2 CS gauge bits (family) + 6 payload bits (micro_ref)
  Alphabet factorizes K4 x GF(2)^6: 256 = 4 x 64
  q6(b): Byte256 -> GF(2)^6 with uniform 4-to-1 fibers (deck group K4)

Operator layer
  128 distinct permutations on Omega (256 bytes mod shadow XOR 0xFE)
  Depth-4 words {id, W2, W2', F} per micro_ref (Klein four-group)
  Full operator group G = (GF(2)^6 x GF(2)^6) semidirect C2, |G| = 8192
  Equivalent form G = (Z/2)^12 semidirect Z/2 (packed signature coordinates)

Code / quantum layer
  Self-dual [12,6,2] mask code C64; weight enumerator (1+z^2)^6 = [2,1,2]^6 direct sum; pair-collapse to GF(2)^6. NOT the classical GF(4) hexacode.
  12-qubit graph state; six Bell pairs; CHSH at Tsirelson bound 2*sqrt(2)
  Stabilizer algebra: 12 commuting GF(2) generators, rank 12

Continuous layer (from CGM axioms, imported as constants)
  UNA -> SU(2) (3 rotational DOF); ONA -> SE(3) = SU(2) semidirect R^3 (6 DOF)
  BU holonomy delta_BU, aperture rho, gap Delta; gyrogroup on velocity space
  GNS representation on L^2(S^2); Q_G = 4 pi steradians

Critical distinction: the continuous groups are Lie-group benchmarks and modal consequences. The finite groups are what the byte engine implements exactly. Bridges are structural analogies unless a script proves an isomorphism or embedding (several no-go theorems say what is NOT a bridge).
