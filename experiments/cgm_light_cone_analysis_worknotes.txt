1. THE GEOMETRIC DICTIONARY (the exact light-cone bridge)
--------------------------------------------------------------------------

Work in Minkowski space M^4, metric diag(+1,-1,-1,-1), c = 1. Three
objects, kept distinct:

  N   = { x : x.x = 0, x0 > 0 }      forward light/null cone  (BOUNDARY)
  H^3 = { q : q.q = +1, q0 > 0 }     forward mass shell       (the SPACE)
  B   = { beta : |beta| < 1 }        Einstein gyroball        (a CHART of H)

Bridge: the projection q -> beta = q_spatial/q0 is a bijection H -> B
(q0 = gamma). B IS the set of future-timelike directions. The boundary
|beta| = 1 is the ideal completion of B and equals the CELESTIAL SPHERE
S^2 = N/R+, the projectivized future light cone - one point per null
direction.

INVARIANT ORDERING (kept clean through all that follows):
  - interior of B  <=> strictly timelike directions (inside the cone)
  - boundary of B  <=> null directions (on the cone)
  - |beta| > 1     <=> spacelike (outside the cone; not a velocity)
H carries the hyperbolic metric of constant sectional curvature -1.
On H, rapidity = hyperbolic distance: d(0, beta) = atanh(beta),
k(beta) = tanh(atanh(beta)/2) is the Poincare half-rapidity radius.

The three earlier drafts (AI/1, AI/2) got this essentially right but
loose: the mass shell is the hyperbolic SPACE, the cone is its IDEAL
BOUNDARY, and the gyroball is a CHART of the shell. Keep that ordering.
